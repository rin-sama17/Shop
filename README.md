# 🛍️ فرش لبخند (Shop)

یک وبسایت فروشگاهی برای خرید و فروش فرش با طراحی واکنش‌گرا و رابط کاربری کاربرپسند.  
این پروژه به‌عنوان نمونه‌کار توسعه‌ی فرانت‌اند من ساخته شده است.

---

## 👨‍💻 نقش من
توسعه‌دهنده **فرانت‌اند**

---

## 🛠️ فناوری‌ها و ابزارهای استفاده شده
- [React.js](https://react.dev/) → ساخت رابط کاربری  
- [Redux](https://redux.js.org/) → مدیریت وضعیت برنامه  
- [Material UI](https://mui.com/) → طراحی کامپوننت‌های مدرن و ریسپانسیو  
- [Axios](https://axios-http.com/) → اتصال به بک‌اند و مدیریت درخواست‌های API  

---

## ✨ ویژگی‌های پیاده‌سازی‌شده
- طراحی صفحات فروشگاه (لیست محصولات، جزئیات محصول، سبد خرید و …)  
- مدیریت داده‌ها با **Redux** جهت بهبود عملکرد و مقیاس‌پذیری  
- رابط کاربری مدرن، ریسپانسیو و کاربرپسند با **Material UI**  
- اتصال یکپارچه به بک‌اند و واکشی داده‌ها با **Axios**
